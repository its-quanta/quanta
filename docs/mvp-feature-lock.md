# Quanta MVP Feature Lock

Quanta is an AI-assisted estimating and tender workspace for small contractors and subcontractors.

The MVP must include:

1. Authentication
2. Organisation profile
3. Project creation
4. Project workspace
5. Document upload
6. Manual takeoff table
7. AI-assisted takeoff draft generation
8. Material takeoff table
9. Labour build-up table
10. Pricing engine
11. Margin and markup calculations
12. Exclusions, assumptions and RFIs
13. Excel export
14. Audit trail/user corrections
15. Basic settings for default rates and margins

The MVP must not include yet:

1. Mobile app
2. Accounting integrations
3. Supplier live pricing
4. Full BIM viewer
5. Team invitations
6. Payments/subscriptions
7. Marketplace
8. Scheduling
9. Invoicing
10. CRM
11. Advanced collaboration
12. Full automatic measuring engine

Product rule:
AI outputs are draft only. Users must review and approve final takeoff/pricing/tender outputs.

Build rule:
Build one vertical workflow at a time. Do not build isolated frontend screens without database backing unless clearly marked as temporary.
